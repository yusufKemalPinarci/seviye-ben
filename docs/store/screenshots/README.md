## Teknik
- **Boyut:** 1080×1920 (9:16)
- **Format:** JPEG (alphasız), &lt; 8 MB
- **Yeniden üret:** `python render_shots.py`

## Play Console
Uygulama listesi → Grafikler → Telefon ekran görüntüleri → bu 4 dosyayı sırayla yükle (en az 2 zorunlu).

İstersen gerçek cihaz görüntüsüyle değiştir; boyut/oran aynı kalsın.
